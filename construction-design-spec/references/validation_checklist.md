# 章节与整文校验清单

在每章生成完成后，以及整文交付前，必须按本清单自检。

## 1. 章节级校验

### 占位符与模板污染

- [ ] 没有残留 `XX`、`XXX`
- [ ] 没有残留“如本工程不涉及此条内容，可删除此条”等模板提示语
- [ ] 没有残留与当前项目无关的示例项目名、示例城市、示例表格值
- [ ] 没有把“样例说明”“注释”“提示语”写进正文

### 项目信息一致性

- [ ] 项目名称、地点、面积、层数、高度、结构形式与已确认信息一致
- [ ] 若出现新参数，来源明确，且符合 `project_info`
- [ ] 推理补充内容已标记 `[推理补充]`
- [ ] 缺依据的重要参数已标记 `[待补充]` 或 `[需人工核验]`

### 合规与风险控制

- [ ] 没有在缺乏依据时直接写出地方审查结论
- [ ] 地方规范、绿建、装配式、人防等内容与项目所在地相符
- [ ] 若知识库不可用，仅输出通用框架，不冒充检索依据

## 2. 整文级校验

- [ ] 章节编号、标题层级、顺序连续
- [ ] 同一参数未在不同章节出现冲突
- [ ] 被裁剪章节在目录和正文中处理一致
- [ ] 所有 `[需人工核验]` 项已集中列出，便于人工复核
- [ ] 最终文档可直接交给用户继续人工完善，不包含明显模板脏数据
