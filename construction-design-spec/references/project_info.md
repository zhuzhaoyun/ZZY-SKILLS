# 项目信息提取 - 提示词

> **注意**: 这是提示词模板，实际使用时需要替换 `{{}}` 中的占位符

---

## 使用方法

在 Step 1（项目信息提取）阶段，使用以下提示词让 AI 提取项目特征：

### 输入

```
请从以下项目描述中，提取建筑施工设计说明所需的的关键特征，并以 JSON 格式输出：

项目描述：
{{project_description}}
```

### 输出要求

必须输出以下 JSON 结构：

```json
{
  "使用功能": {
    "建筑名称": "项目或单体名称",
    "建筑类别": "如：一类高层民用建筑/高度分类",
    "计容面积": "数值+单位"
  },
  "项目位置": "详细到省市区县及道路",
  "规划条件": {
    "土地使用性质": "分类后的标准用地名称",
    "气候分区": "推理或提取的结果",
    "抗震设防烈度": "如：7度(0.10g)"
  },
  "建设单位": "业主方全称",
  "工程设计等级": "如：特级/一级",
  "安全等级": {

  },
  "地形地貌": {
```

---

## 提取规则

1. **原文明确存在的参数**：直接提取原文中的参数值

2. **原文未提及的常见参数**：根据项目位置、建筑类型等信息自行推理补充，推理结果用 `[推理补充]` 标注。例如：
   - 气候分区：根据项目所在城市推断（寒冷北方→严寒/夏热冬冷，南方沿海→夏热冬暖/夏热冬冷）
   - 土地使用性质：归类为标准用地名称（居住用地、公共管理与公共服务用地等）
   - 其他常见参数（耐火等级、防水等级等）：根据建筑类型和规范要求推理

3. **单位保留**：所有数值（如面积、高度、标高、年限）必须保留原文中的**物理单位**（如 m², m, 年）

## 需要用户补充的信息

如果提取后缺少以下关键信息，需要请用户补充：

- [ ] 建筑名称
- [ ] 建筑面积/计容面积
- [ ] 建筑高度/层数
- [ ] 结构形式
- [ ] 气候分区（如无法从位置推断）
- [ ] 耐火等级
- [ ] 防水等级
- [ ] 节能标准
